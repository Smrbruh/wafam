QADAM — Build with AI, задача 1

1. Локальное демо с Gemini: http://localhost:4173
   Сервер сейчас работает. Для нового запуска: npm start (из корня репозитория)
   Node.js 22+. Установка npm-пакетов не требуется.

2. Ключ Gemini: .env (только на вашем компьютере).
   Он НЕ входит в Git или архив. Для нового компьютера скопируйте .env.example в .env.

3. Презентация и тестовые сценарии: папка submission.
   PPTX содержит изображения проверенных слайдов; текст не редактируется как отдельные объекты.

4. Приватный hosted preview (без серверного Gemini):
   https://qadam-astana-walks.asanabilmansur.chatgpt.site

5. Демонстрационные скриншоты и короткий silent walkthrough: папка demo.
   Это видео из реальных скриншотов работающего приложения, без озвучки.
   Полный сценарий записи и текст выступления: submission/Qadam_Demo_and_Speaker_Notes.txt.
   YouTube: видео ещё не загружено. Загрузите запись в свою учётную запись и сдайте ссылку.
